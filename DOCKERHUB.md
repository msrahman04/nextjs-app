# nextjs-app

A Next.js app packaged as a Docker image.

## Usage

```bash
docker run -p 3000:3000 shahinur093/nextjs-app:latest
```

## Tags

- `latest` — most recent build from `main`
- `sha-<commit>` — immutable build for a specific commit
- `<version>` — semver release built from a `v*` tag
